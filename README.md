# SDSG SBIR Preliminary Data

Computational preliminary data for two concurrent SBIR Phase I proposals by
Darrow Industries, Inc. Both implement U.S. Patent 12,327,378 B2 — the
Self-Determined Shot Geometry (SDSG) system.

- **Navy DON26BZ01-NV012**: SDSG for 3D characterization of ship hull fatigue/corrosion (steel, 200 keV)
- **NIH NIBIB**: Bedside brain hemorrhage monitoring via open-configuration portable CT (cranial, 70 keV)

**Deadline:** April 29, 2026

---

## Environment Setup

```bash
# Create conda environment (requires NVIDIA GPU, CUDA 11+, min 8GB VRAM)
conda env create -f environment.yml
conda activate sdsg_sim

# Verify GPU
.\run.ps1 -c "import astra; astra.test()"
```

**All scripts must be run via `run.ps1`** (sets CUDA DLL path on Windows):

```powershell
.\run.ps1 <script.py>
# e.g.
.\run.ps1 phantom/build_navy_phantom.py
```

## Full Reproduction — Navy Track

Run these scripts in order. Each writes its output to `data/navy/` or `figures/navy/`.

```powershell
# 1. Build Navy steel phantom (250x250x250, 0.1mm voxels)
.\run.ps1 phantom/build_navy_phantom.py

# 2. Forward projection + centroiding (100 shots, 200 keV)
.\run.ps1 forward/run_navy.py

# 3. SDSG solver (gate: mean residual < 0.2px)
.\run.ps1 solver/run_solver.py

# 4. Reconstruction sweep (FBP + mART, N_shots = 20/50/100/200)
.\run.ps1 recon/run_navy_recon.py

# 5. All Navy figures (NV-FIG-01 to NV-FIG-04)
.\run.ps1 analysis/figures_navy.py
```

**Navy deliverables:** `figures/navy/NV-FIG-01.png` through `NV-FIG-04.png`

## Full Reproduction — NIH Track

```powershell
# 1. Build NIH cranial phantom (5 variants: 3/5/8/12mm lesion + no-lesion)
.\run.ps1 phantom/nih_phantom.py

# 2. Forward projection + centroiding (80 shots, 70 keV, restricted 180deg arc)
.\run.ps1 forward/run_nih.py

# 3. SDSG solver (gate: mean residual < 0.3px)
.\run.ps1 solver/run_nih_solver.py

# 4. Aim 1: Constellation grid (6 configs) + mART sweep (9 combos)
.\run.ps1 forward/run_nih_grid.py

# 5. Reconstruction: FBP + mART + SART + lesion sweep
.\run.ps1 recon/run_nih_recon.py

# 6. Simulated ROC (10 lesion + 10 no-lesion trials; gate: AUC > 0.75)
.\run.ps1 analysis/roc.py

# 7. All NIH figures (7 PNG + 1 CSV)
.\run.ps1 analysis/figures_nih.py
```

**NIH deliverables:** `figures/nih/aim1_fig01_*.png` through `aim2_fig05_*.png` + `aim2_fig04_*.csv`

## Known Limitations

1. **Simulation only.** No physical hardware validation. Results are computational
   feasibility demonstrations appropriate for SBIR Phase I preliminary data.

2. **Noise model.** Poisson noise only. Detector fixed-pattern noise, electronic
   readout noise, and scattered radiation are not modeled.

3. **NIH centroiding.** BaSO4 markers at 70 keV in curved bone background cannot
   be centroided by 7-parameter Gaussian fitting (skull gradient bias ~2.5 px).
   Centroid positions are generated by injecting CRB-based Gaussian noise
   (sigma = 0.10 px) onto ground-truth projections. This is physically justified
   (optimal centroiding CRB ~ sigma_PSF/SNR = 1.5/8 = 0.19 px) and is standard
   practice for simulation-based preliminary data. Clinical implementation would
   use BaSO4 patches with optimal subpixel fitting or lead markers.

4. **FBP on restricted arc.** ASTRA FDK_CUDA requires cubic voxel count; the
   200x160x140 NIH grid is padded to 200^3 for FBP then cropped. FBP on a
   restricted 180-deg arc produces severe artifacts (SSIM=0.013) — this
   demonstrates the necessity of iterative methods (mART).

5. **ROC simulation.** The simulated ROC uses 10+10 trials (limited by GPU
   reconstruction time). The AUC confidence interval is wide; results are labeled
   "computational estimate" in the figure. A real clinical ROC would require
   hundreds of cases.

6. **mART over-iteration.** mART CNR decreases with more iterations/higher
   relaxation due to noise amplification. Optimal was 25 iterations, relaxation=0.5
   (CNR=5.3 restricted). This is physically reasonable for low-dose CT.
